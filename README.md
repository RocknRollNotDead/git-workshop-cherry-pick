# Воркшоп по git - cherry-pick

Контекст - в командной работе, когда несколько людей параллельно работают над одним репозиторием, нередко возникает ситуация, когда необходимо перенести какие-то изменения между ветками, не делая их полного слияния.

Для этого существует специальная команда - cherry-pick. Однако, как и при любых других способах переноса изменений, могут возникнуть конфликты, которые необходимо решить.

Суть задачи:
- Есть две ветки, иллюстрирующие работу двух разработчиков параллельно - `feature-telegram-bot-adapter-route` и `feature-interval-repetition-service-route`
- Необходимо переключиться на ветку `feature-telegram-bot-adapter-route` и перенести в неё коммит `645fd375` из ветки `feature-interval-repetition-service-route`, не вливая её целиком

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
- Сравнение с remote веткой должно показать изменения в файлах
- Проверьте, что тесты проходятся (их можно прогнать командой `./gradlew test`)
